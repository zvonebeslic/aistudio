✦ Poveži Google Gemini za AI generiranje

Na GitHub Pagesu možeš koristiti vlastiti API ključ za ovu karticu preglednika. Ključ se ne sprema u galeriju, localStorage ni GitHub i briše se zatvaranjem ili osvježavanjem stranice. Budući da se zahtjev šalje iz tvog preglednika, ovo nije sigurnosna zamjena za backend: ključ može biti vidljiv u alatima preglednika i drugim skriptama. Koristi ga samo za osobni rad, s ograničenjima troškova. Za javni produkcijski studio preporučen je backend.

Foto editor i Video montaža obrađuju tvoje datoteke lokalno i besplatno, bez API ključa. Galerija ostaje u ovom pregledniku. Nano Banana i Omni koriste tvoj Google API račun i mogu se naplaćivati po generiranju.

Za stalnu online pohranu, višekorisnički pristup i sigurno čuvanje tajnih ključeva potreban je backend. Puni izvorni kod i upute su u README datoteci na GitHubu.
